# BaseForge v0.6.2-beta

BaseForge artık **İngilizce öncelikli**. Bu sürümle Designer İngilizce/Türkçe oldu, NuGet'teki README İngilizceye çevrildi ve yeni bir [dokümantasyon sitesi](https://dropdeart.github.io/BaseForge/tr/) yayına girdi. Kütüphane paketlerinde davranış değişikliği yok; sürüm numarası generator ile birlikte hizalı kalsın diye tüm paketler yükseltildi.

## Yenilikler

### İngilizce ve Türkçe Designer
- Designer arayüzü artık **İngilizce** ve **Türkçe**. Soldaki rayın altındaki **EN / TR** düğmeleriyle değiştirilir.
- Seçim tarayıcıda hatırlanır. Kayıtlı bir seçim yoksa tarayıcı dili belirler (Türkçe tarayıcıda Türkçe, diğerlerinde İngilizce açılır).
- Tüm arayüz metinleri `src/BaseForge.Designer.Web/src/i18n/` altında. `en.ts` asıl kaynak; `tr.ts`'te eksik anahtar varsa derleme hata verir.

### Dokümantasyon
- Yeni dokümantasyon sitesi: başlarken, Designer turu, servis spec'i referansı, Identity ve yetkilendirme, CLI referansı, production'a yayın rehberi, mimari kararlar — İngilizce ve Türkçe.
- nuget.org'da görünen README artık İngilizce; Türkçesi `README.tr.md`'de.
- Repoya MIT `LICENSE` dosyası eklendi (paketler zaten MIT lisanslıydı).

## Henüz Türkçe olanlar

CLI mesajları, spec doğrulama hataları ve üretilen koddaki yorumlar hâlâ Türkçe. Bunlar sonraki bir sürümde çevrilecek.

## Yükseltme
```
dotnet tool update -g BaseForge.CodeGen --prerelease
```
Yeniden üretilen servisler `BaseForge.*` 0.6.2-beta paketlerini referans alır; 0.6.x ile üretilmiş servislerde kod değişikliği gerekmez.
