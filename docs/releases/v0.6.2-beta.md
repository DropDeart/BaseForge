# v0.6.2-beta

BaseForge goes **English-first**. This release brings an English/Turkish Designer, an English README on NuGet and a brand-new [documentation site](https://dropdeart.github.io/BaseForge/). No behavior changes in the library packages; all packages were bumped so the version stays aligned with the generator.

## New

### Designer in English and Turkish
- The Designer interface is now available in **English** and **Turkish**. Switch with the **EN / TR** buttons at the bottom of the left rail.
- Your choice is remembered in the browser. Without a saved choice, the browser language decides (Turkish browsers open in Turkish, everything else in English).
- All UI strings live in `src/BaseForge.Designer.Web/src/i18n/`. `en.ts` is the source of truth, and the build fails if `tr.ts` misses a key.

### Documentation
- New documentation site: getting started, Designer tour, service spec reference, Identity & authorization, CLI reference, production deployment guide, architecture decisions — in English and Turkish.
- The README shown on nuget.org is now in English; a Turkish version lives in `README.tr.md`.
- The repository now includes an MIT `LICENSE` file (the packages were already MIT-licensed).

## Still in Turkish

Messages from the CLI, spec validation errors and comments in generated code are still Turkish. They will be translated in an upcoming release.

## Upgrade
```bash
dotnet tool update -g BaseForge.CodeGen --prerelease
```
Regenerated services reference the `BaseForge.*` 0.6.2-beta packages; services generated with 0.6.x need no code changes.
