# v0.6.1-beta

A Designer bug-fix release. No behavior changes in the library packages; all packages were bumped so the version stays aligned with the generator.

## Bug fixes

| Area | Problem | Fix |
| --- | --- | --- |
| Designer | The ⏻ icon on the left and "Close" at the top showed nothing (the server shut down in the background but the tab stayed as it was) | A "Closing… / Closed" screen; the tab closes if the browser allows it. `/api/shutdown` responds immediately, then the started containers and the process shut down |
| Designer | Closing the tab without pressing "Close" left the process and port open | Tab heartbeat (`/api/heartbeat`): if the heartbeat stops for 3 minutes, the Designer shuts itself down |
| Designer | Crashed with a Kestrel exception when the port was taken (`baseforge new` a second time) | An explanation is printed and the next free port is used |
| Designer | The entity name could not be cleared completely (the first letter came back) | The name input keeps a local draft; an empty/colliding name is shown with a warning, and only a valid name is applied |

## Improvements
- **List filters** and **visibility filter** in separate, annotated cards: chips with field types, selected count, an example query line (`GET /api/…?status=…`), a titled condition table and a separate "who sees everything" section.

## Upgrade
```bash
dotnet tool update -g BaseForge.CodeGen --prerelease
```
Regenerated services reference the `BaseForge.*` 0.6.1-beta packages; services generated with 0.6.0-beta need no code changes.
