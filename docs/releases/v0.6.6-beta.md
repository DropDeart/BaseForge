# BaseForge v0.6.6-beta

Bug fix release.

## Logging

- **Loki queue is now bounded.** The Grafana Loki sink used an unbounded queue: when `Serilog:LokiUrl` was set but Loki was unreachable, every undelivered log event stayed in memory. A production service grew to ~6 GB of RAM in 6 days this way. The queue is now capped at 10,000 events (oldest are dropped first) and can be changed with `Serilog:LokiQueueLimit`.

No breaking changes. Update the package version; nothing else is needed.
