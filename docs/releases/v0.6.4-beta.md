# v0.6.4-beta

The first cut of **companies (multi-tenancy) in Identity**. The full set arrived in [v0.6.5-beta](/releases/v0.6.5-beta): one-time codes, SMTP, password reset, tenant-aware events, list filters and the Designer fields. Upgrade straight to 0.6.5-beta.

## Identity
- `auth.yaml` `multiTenancy`: self-service companies with platform approval, invitations and join requests, roles per company, last-admin guard.
- The token carries `tenant_id`, `tenant_name` and the active company's roles. Switch companies with the `tenant_id` parameter.
- `registration.selfAssignableRoles` and `POST /api/account/roles/{role}`.
- `/api/*` errors are ProblemDetails.
- `System.Security.Cryptography.Pkcs` is pinned to 10.0.14.

::: warning Designer
The Designer in this version does not know the `multiTenancy` fields yet. Saving the Identity from the Designer drops them. Fixed in 0.6.5-beta.
:::
